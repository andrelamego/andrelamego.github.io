# André Lamego Portfolio

Portfolio interativo em React, TypeScript e Vite para apresentar currículo, projetos e contato de André Lamego em uma experiência inspirada em sistemas operacionais.

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run preview
```

## Conteúdo

As informações públicas do site foram alinhadas ao currículo:

- Desenvolvedor Backend Java com foco em Spring Boot, APIs REST, Clean Architecture e Kafka.
- Projetos Muttley e BR Validator.
- Formação em Análise e Desenvolvimento de Sistemas pela FATEC Zona Leste, 2024-2028.
- Competências técnicas, idiomas e contatos.
